\# 📚 PDF + AI 智能题库生成器



一个基于 PDF 文档和 AI 大模型自动生成题库的 Python 工具。



\## ✨ 功能特点



\- 📄 解析 PDF 文档内容

\- 🤖 调用 AI 大模型自动生成题目

\- 📝 支持多种题型（选择题、填空题、问答题等）

\- 💾 导出题库到 Excel/JSON 格式



\## 🛠️ 技术栈



\- Python 3.x

\- PyPDF2 / pdfplumber（PDF 解析）

\- OpenAI API / 其他大模型 API

\- pandas（数据处理）
